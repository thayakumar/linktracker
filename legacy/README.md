# Earlier implementations

- `apps-script-index.html` is the earlier Apps Script-hosted UI.
- `apps-script-hosted-index.html` preserves the previous root page from the repository.
- `node-index.html` is served only by the optional Node/SQLite backend (`npm start`).

The current app uses root `index.html`, `src/`, and the JSON-only `apps-script/Code.gs`. Do not paste these legacy HTML files into Apps Script for the current architecture.
